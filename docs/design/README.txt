يوزرسيف — تصدير الديزاين كـ HTML

افتح index.html في أي متصفح: فيه كل الشاشات (120) مترتبة زي الكانفاس.
كل شاشة صفحة HTML لوحدها، والأزرار والفورمز واللينكات بين الشاشات شغالة.
الصور والمكتبات جوه فولدر assets، فالملفات بتشتغل من غير إنترنت.
الخط (Cairo) بيتحمّل من Google Fonts، فمن غير إنترنت هيظهر خط بديل.

الشاشات بتستخدم React 18 وملف assets/dc-lite.js اللي بيقرا التمبليت ويعرضه.
ده تصدير للتصميم كنموذج تفاعلي، مش كود الإنتاج النهائي: البيانات تجريبية ومفيش سيرفر.
